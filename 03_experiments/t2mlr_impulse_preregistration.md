# Non-training Phase-A completion

Fixed before inspecting these new impulse measurements. All six frozen checkpoints, same 256 WikiText and 256 MATH-500 input records and reset positions as C-T2-SIX. Existing carry_off results are reused. No Jacobi/causal training.

Arms: zero reset with natural KV; zero reset with clean history KV; two independent fixed random tangent directions, each under natural and clean KV (six interventions). Small perturbation: project seeded Gaussian vector orthogonal to incoming state, normalize it, add 0.05 times the state's norm, renormalize to original norm, then cast to execution dtype. Record actual relative displacement and norm ratio after casting. Seeds derive from SHA256(document ID, direction index), fixed across runs. Two directions are repeated interventions within a document, never independent samples.

Normal and perturbed trajectories advance in lockstep with separate mutable caches. For clean-KV use a fresh clone of normal history before each step; keep perturbed recurrent state. Branches fork from identical normal prefix immediately before the earliest intervention in the batch. Per-row reset masks handle different math prompt lengths. Right padding and targets beyond the input's valid end are never analyzed. Observe lag 0–127; truncate computation beyond the final required target without altering any preceding causal outputs.

Per token: KL(normal || intervention) from FP32 log-softmax over full vocabulary; relative L2 and cosine distance between post-transition states; signed and absolute target ΔNLL. State response means relative L2 divided by normal state's norm (not cosine), optionally divided by actual injected relative displacement for input-normalized gain. Store raw unclamped KL too; check numerical negatives and clamp only tiny numerical negatives for the nonnegative summary.

Primary AUC: discrete sum over lag 1–64 inclusive; include only examples with all 65 targets including lag 0. Publish eligible n. State and output KL AUC separately. Direction-averaged small-perturbation endpoints average the two directions within each example before 2,000 document-level bootstrap resamples (seed 0); also report each direction.

Recovery time: first lag t>=1 for which five consecutive response values are <=0.5 or <=0.1 times lag-0 response, separately for relative state L2 and KL. No exponential fit. Use only examples with complete lag 0–127 (Wiki n=256, Math n=169), eligible event starts 1–123. No event is right-censored; report recovery fraction, observed-event count and restricted mean with censor encoded as 124, not an uncensored mean/half-life. If lag-0 response <=1e-10, mark undefined rather than instantly recovered. A threshold crossing may be followed by rebound; the five-step criterion is not permanent disappearance.

All six cells' state/KL curves are BF16 execution diagnostics, not proof of semantic memory or contraction eigenvalues; small-perturbation residuals may reach a numerical floor. Report this limitation and full curves. NLL far windows and natural-clean paired differences supplement the primary metrics. Previously observed 362M/50B math exception receives the same measures; no sample selection based on effect. Repeating the same data is implementation/metric follow-up, not independent confirmation.

Validation: tiny-model single-trajectory equivalence, variable reset prefix controls, perturbation norm/determinism, censor handling; full-weight official exact-step parity per model, no-op-prefix equality and finite metrics. Default batch 32, per-cell cap 3,600 seconds; overall cap 14,400 seconds. Complete paired batches only, never silently reduce n on timeout. No-op and calibration checks cannot substitute for the primary experiments. Raw arrays, IDs, actual injections, manifests and code/data hashes retained.

Clarification before inspecting impulse outcomes: direction-mean recovery is computed on each document's mean of the two direction response curves; per-direction recovery is also reported. It is not two independent observations.
