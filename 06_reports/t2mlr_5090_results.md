# T²MLR 982M recurrent 机制实验：RTX 5090D

日期：2026-09-18。实例：`pro-78730289ac36`，单张 RTX 5090D 32GB。

## 当前结论

**这个冻结 checkpoint 强依赖反馈融合路径；旧状态的加法累积提供稳定但较小的收益。单次状态清零或替换未造成可观的远期平均预测损失。** 当前证据更符合短时特征复用、状态可被后续输入与 attention 历史重建的解释，不能据此认定模型已实现持续 latent reasoning，也不能认定它没有任何长程状态信息。

主实验、独立确认和探索性补测都完整完成。**非负差异补测显示：扰动大幅衰减，但残留没有完全消失，平均 NLL 确实包含正负抵消。** 结果不是 1.7B retrofit benchmark 的复现，也没有参数/训练匹配的 Transformer 或 RLT 对照。

## 设置与验证

- 模型：`JupiterZhu/T2MLR_982M_lstart9_lend24_50B_FineWebEdu`，revision `5061964f36236336153106d4b11155e09ee2daaa`。
- 官方代码：`2871fa204e4cc145fd67d7d1a82b319c2010e9dc`；Transformers 4.56.2，PyTorch 2.8.0+cu128，BF16，eager attention，精确逐 token 推理。
- WikiText-103-raw-v1，revision `b08601e04326c79dfdd32d625aee71d232d685c3`；主实验取 validation 前 32 篇合格完整文章，确认取 test 前 32 篇。每篇 512 个预测位置，batch=4，无 BOS、不跨文档拼接。
- 主实验在位置 128 前干预，确认在位置 256 前干预；其他输入和位置完全一致。自然条件保留受扰后的 KV，clean-KV 条件每步使用正常历史 KV，但保留受扰 state 的演化。
- 数据可能与预训练重叠；用于冻结权重的内部依赖诊断，不作为泛化成绩。
- 完整 safetensors SHA-256 校验通过；所有权重严格加载、tied embedding/head 相等。完整权重 2×8-token BF16 对照的 logits/state 最大差异均为 0；4 项 tiny CPU 测试通过。
- 主实验及确认所有单次干预的前缀 NLL 最大差异均为 0；主实验 fusion_off 与 fusion_and_carry_off 的全轨迹 NLL 完全相同。

正常模型 warmup 后平均 NLL：主实验 2.338725，确认 2.458751（PPL 10.368 / 11.690）。这是本次截断、无 BOS 设置下的值，不能直接比较论文榜单。

## 主终点：远期平均效应

以下为干预后 lag 32–127 的配对 ΔNLL，单位 nat/token；括号内为 2000 次 bootstrap 95% CI。预先指定实用等效区间为 ±0.01。

| 条件 | 主实验，32 篇 | 独立确认，32 篇 |
|---|---:|---:|
| 单次清零，自然 KV | +0.000632 [−0.001317, +0.002734] | −0.000512 [−0.001784, +0.000822] |
| 单次清零，clean-KV | −0.000534 [−0.001455, +0.000388] | +0.000125 [−0.000806, +0.001114] |
| 同范数跨文档 donor | +0.000974 [−0.000895, +0.002878] | +0.001098 [−0.001116, +0.003267] |

这些远期 CI 均完整落入等效区间。它们支持“平均预测代价很小”，不是依靠宽 CI 和不显著性宣称无效。donor 按 8 个完整供体 batch 重采样，其余按 32 篇文档重采样。

自然 KV 条件本身就没有明显远期平均代价，因此当前不能宣称“长程效应主要由 KV 而不是 state 承担”。该路径归因需要先观测到足够大的长程效应。

## 持续消融：反馈读取与加法累积贡献不同

下表统计位置 32–511 的配对 ΔNLL。

| 条件 | 主实验均值 [95% CI] | 确认均值 [95% CI] |
|---|---:|---:|
| 每步 state 清零，保留融合模块 | +5.1367 [5.0533,5.2208] | 未重复 |
| 绕过整个融合模块 | +2.7824 [2.7165,2.8580] | 未重复 |
| 移除 state 加法累积，保留归一化 | +0.02192 [0.01748,0.02644] | +0.01637 [0.01214,0.02051] |
| 每 8 步清零 | +0.21740 [0.20427,0.23140] | 未重复 |
| 每 32 步清零 | +0.04132 [0.03453,0.04799] | 未重复 |
| 每 128 步清零 | +0.00800 [0.00509,0.01081] | 未重复 |

累积项有稳定小幅贡献，约对应 PPL 增加 2.2% / 1.7%。但这与持续清零的破坏量级完全不同。`carry_off` 仍然将上一步中层输出反馈到当前 token，只是取消状态自身的额外相加。

每步清零比整个融合旁路更差，提醒我们零状态在训练好的融合模块中可能造成明显分布偏移。两种操作都不是训练匹配的 Transformer baseline。

周期清零更频繁造成更大平均损失，与反复施加短期扰动相容，不能直接把 8/32/128 解读成模型记忆长度。

## 探索性补测：衰减与抵消同时存在

在看过主实验后，对相同 32 篇 validation 文章补测输出 KL(normal || intervention)、state 相对 L2 距离、cosine distance 和绝对 ΔNLL。这些结果是探索性，不是另一个独立确认集。

| 条件与指标 | 当步 lag 0 | lag 1–7 | lag 8–31 | lag 32–127 |
|---|---:|---:|---:|---:|
| 自然 reset，KL | 0.54662 | 0.04222 | 0.00317 | 0.001024 |
| clean-KV reset，KL | 0.54662 | 0.00617 | 0.000367 | 0.000376 |
| donor，KL | 0.63794 | 0.03914 | 0.00296 | 0.001147 |
| 自然 reset，state 相对 L2 | 0.38158 | 0.05556 | 0.01588 | 0.01007 |
| clean-KV reset，state 相对 L2 | 0.38158 | 0.02648 | 0.00588 | 0.00579 |

自然 reset 的远期 KL 95% CI 为 [0.000747,0.001429]，clean-KV 为 [0.000357,0.000397]；二者都非零。自然 reset 的远期绝对 ΔNLL 仍为 0.02712 [0.02435,0.03033]，明显大于有符号均值 +0.000632；clean-KV 的绝对值为 0.01789 [0.01694,0.01889]。

所以“远期 NLL 平均接近零”确实部分来自有利和不利变化抵消，不能称为输出完全恢复。同时 KL 和 state 距离从当步到远期下降很多，也不能将均值接近零全部归因于抵消而忽略实际衰减。

clean-KV 的残留差异更小，与 attention 历史参与扰动传播相容；这仍不是 KV 对有用长程信息的贡献百分比。未做 FP32 对照，低幅度残留中的 BF16 数值效应没有单独分离。也未设定 KL/state-distance 的确认性等效阈值，不将它们强行套入 NLL 的 ±0.01 标准。

## 统计与解释边界

主终点与 ±0.01 阈值在看结果前确定；近端、周期清零及 donor 的局部窗口是次要分析，CI 未做多重比较校正。补充 KL/state-distance 分析在主结果之后提出，明确标为探索性。

这一轮没有测试可验证多步推理任务，也没有移除 attention 历史。状态信息可以被保留但不影响平均 NLL，也可能由 KV 快速重建。非负差异补测已经显示少量持续变化，不能把快速恢复的平均预测代价等同于不存在持续状态信息。
