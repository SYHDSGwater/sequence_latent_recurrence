# T²MLR 扩大机制实验：135M/10B 与 982M/50B

四组实验全部完成。结论从上一轮的小样本文本扩展到两个公开 checkpoint、256 篇文章和 256 道数学题：冻结模型依赖反馈路径，旧状态加法累积提供小幅平均预测收益；单次清零后的远期平均预测代价很小，但逐 token 差异没有完全消失。结果没有建立持续 latent reasoning，也没有检验论文 1.7B retrofit 的数学准确率。

## 配方与样本

实例为用户指定的 `pro-78730289ac36`，GPU 运行时报告 NVIDIA GeForce RTX 5090，32 GB。BF16、PyTorch 2.8.0+cu128、Transformers 4.56.2，官方逐 token exact inference 适配器，完整 attention KV，teacher forcing，无训练。

| 条件 | 135M/10B | 982M/50B |
|---|---|---|
| checkpoint 标签 | T2MLR_135M_lstart13_lend18_10B_FineWebEdu | T2MLR_982M_lstart9_lend24_50B_FineWebEdu |
| 固定 revision | 2bbdb5540e56aaf09b2a5e80e63fcf57d629d3db | 5061964f36236336153106d4b11155e09ee2daaa |
| 实际去重参数数，包含反馈模块 | 136,175,042 | 993,366,530 |
| 循环层范围，1-based | 13–18 | 9–24 |
| 普通文本 / 数学样本数 | 256 / 256 | 256 / 256 |

参数量、训练 token 数与循环层范围同时变化，跨 checkpoint 比较不能识别纯参数规模效应。

普通文本从 WikiText-103 raw 的 train split 重建 29,436 篇文章，用固定随机种子 20260918 选择 256 篇满足 513-token 长度要求的独立文章，评分 512 个 next-token targets。与上一轮实际测量的 64 篇文章没有标题重叠。train 是数据集原始 split 名称，本轮没有训练；不能排除公开语料与模型预训练重叠。

数学从 MATH-500 的 500 道题中排除 4 道 prompt 超过 512 tokens 的题，再随机选择 256 道。覆盖 Algebra 68、Intermediate Algebra 56、Prealgebra 40、Precalculus 32、Number Theory 29、Counting & Probability 16、Geometry 15；难度 1–5 分别为 28、48、55、60、65 题。输入为 `Problem:\n{problem}\nSolution:\n` 与参考解答分别 tokenize 后拼接，不自动添加 BOS，最多评分前 256 个解答 tokens，共 44,306 个解答 targets。两个 checkpoint 对全部输入的 tokenization 相同。

每个模型处理相同的 512 个独立输入，因此共有 1,024 次模型–输入评估；独立输入数仍为 512，不能说成 1,024 个独立样本。五个条件均在同一输入上配对：normal、reset_once、reset_once_clean_kv、carry_off、zero_every。此轮没有扩展 donor、周期重置、KL 或 state-distance 测量。

普通文本在输入位置 128 前重置状态；数学在最后一个 prompt token 被消费前重置，lag 0 对应第一个参考解答 token 的损失。持续干预从整个输入开头执行，数学只对解答 targets 计分，因此其效应同时包括题目编码与解答阶段的改变，不能归因于解答阶段独有的累积。

clean-KV 每步恢复正常运行的历史 KV，同时保留受扰状态继续演化；carry_off 只移除旧状态加法残差，保留反馈读取和归一化；zero_every 每步清零输入状态，但融合模块仍工作。所有干预均可能改变冻结模型的内部输入分布。

## 主要结果

以下为相对正常运行的文档/题目平均 ΔNLL，单位 nat/token；正值表示干预有害。括号为独立文章/题目级 2,000 次 bootstrap 的点态 95% CI，未校正多重比较。

| checkpoint / 数据 | 去掉累积项 carry_off | 每步清零 zero_every | 单次清零远期 lag 32–127 |
|---|---:|---:|---:|
| 135M / Wiki | +0.01950 [0.01749, 0.02156] | +1.63660 [1.61276, 1.66127] | +0.00147 [0.00056, 0.00254] |
| 135M / Math | +0.03165 [0.02632, 0.03709] | +1.84674 [1.75427, 1.93814] | −0.00085 [−0.00167, 0.00001] |
| 982M / Wiki | +0.02041 [0.01883, 0.02193] | +5.09889 [5.06351, 5.13524] | +0.00090 [0.00012, 0.00172] |
| 982M / Math | +0.02451 [0.02066, 0.02862] | +4.74335 [4.65184, 4.83259] | −0.00102 [−0.00210, 0.00006] |

持续干预均为 n=256；普通文本远期 n=256，数学远期 n=169，仅纳入至少具有 128 个解答 targets 的题。其余 87 题没有足够长度，不能算作“无远期效应”。各条件先对每个独立样本求均值，再跨样本平均，长题不会因为 tokens 多而占更大权重。

四组自然重置与四组 clean-KV 的远期 CI 均完整落在事先固定的 ±0.01 nat/token 实用小效应区间。普通文本自然重置的 CI 虽然排除零，但效应仍远小于该阈值；统计可检测与实际大小是不同问题。

| checkpoint / 数据 | clean-KV 远期有符号 ΔNLL，95% CI | 自然重置远期平均绝对 token ΔNLL | clean-KV 远期平均绝对 token ΔNLL |
|---|---:|---:|---:|
| 135M / Wiki | +0.000134 [−0.000192, 0.000476] | 0.02723 | 0.01625 |
| 135M / Math | −0.000320 [−0.000785, 0.000175] | 0.03059 | 0.01768 |
| 982M / Wiki | −0.000183 [−0.000506, 0.000138] | 0.02999 | 0.01803 |
| 982M / Math | +0.000146 [−0.000394, 0.000672] | 0.03904 | 0.02032 |

绝对差明显大于有符号均值，说明正负变化相互抵消。恢复 clean KV 后绝对差较小，与 KV 参与扰动传播相容，但仍有状态路径残留。不能把两列相减解释成可加的“KV 贡献百分比”；也没有 FP32 对照来进一步分离 BF16 数值传播与语义影响。

单次清零当步 ΔNLL：135M/Wiki +0.2421 [0.1354,0.3549]，135M/Math −0.0089 [−0.0597,0.0385]，982M/Wiki +0.9266 [0.7174,1.1585]，982M/Math +0.3129 [0.2619,0.3649]。135M/Math 当步平均代价不确定，但随后 1–7 步为 +0.03795 [0.03025,0.04562]。这不支持“重置后每一步都必然变差”。数学与普通文本的干预位置不同，不能据此识别纯领域效应。

## 跨 checkpoint 的含义

982M 正常预测的文档平均 NLL 更低：Wiki 2.4431 对 135M 的 3.4453，Math 2.5902 对 3.5532。这只是本次固定输入和评分配方下的参考 token 预测表现，不是标准 benchmark 成绩或解题准确率。

982M 每步清零损失更大，但 carry_off 并没有随之增强。配对的“982M 干预效应减 135M 干预效应”：Wiki carry_off 为 +0.00091 [−0.00154,0.00335]，Math 为 −0.00714 [−0.01274,−0.00150]。后者为点态比较，解释上仍受模型、训练量、循环跨度混杂限制。更强的路径依赖不能直接解释为更强的累积推理。

探索性地看，carry_off 使样本平均损失增加的比例分别为 87.9%、76.6%、95.7%、80.1%。因此小幅平均收益并非只由一个离群样本产生，但也不是每个输入都受益。此比例和分位数为补充描述，不是预注册主终点。

## 结论边界与下一步

H-T2-LOCAL 得到跨 checkpoint、跨输入分布的补强：在完整 KV 与正确历史 tokens 持续可见时，单次状态缺失的平均预测代价主要集中在早期，远期代价很小。这与局部复用或可重建状态相容，不能区分二者，更不能推出状态没有长期信息。

H-T2-PERSIST 中的“旧状态累积有预测收益”得到四组支持；“持续且内容特异的多步推理状态”仍未被建立。此次没有语义正确/错误的中间状态替换，没有 attention 可见历史受限对照，也没有自由生成数学答案。

H-T2-KV 获得描述性补强：恢复 clean KV 后非负预测差异更小。但两条路径有非线性交互，且远期平均代价本来就小，不能声称 KV 主导长期记忆。

本轮新增数学题主要扩展了参考解答文本的分布范围。正确前文由 teacher forcing 持续提供，可能让模型通过 attention 重建中间量；解答流畅性、格式与算术符号预测均混在 NLL 中。不能把本轮结果写成“已验证数学推理机制”，也不能用它否定尚未测量的 1.7B retrofit。

若继续研究，优先改变识别设计：在解答内部固定多个中间量边界，比较语义正确/错误且幅度匹配的状态替换，同时限制可供 attention 重建的历史，最后测可验证答案或中间变量。单纯继续扩大同一 teacher-forcing 配方的样本量，主要提高精度，难以解决这些机制混淆。

## 验证、耗时与产物

四个正式运行均完成全部 256 个样本，耗时分别 234.0、161.1、333.6、218.9 秒，合计 947.6 秒，约 15.8 分钟。该时间包含各次模型加载与短序列一致性检查，不包括首次下载、环境准备、先前 batch-16 吞吐试跑及文件取回，不能当作实例总计费时长。

完整权重严格加载；每次运行 2×8 tokens 的 BF16 logits/state 与未修改官方 exact 单步方法最大差均为 0；全部单次干预前缀与正常路径完全相等，两个 KV 条件的 lag 0 完全相等。独立本地重算验证了所有完成状态、数据/代码哈希、唯一 ID、跨模型配对和所有统计汇总。CPU 机制测试 5 项及变长窗口统计测试 1 项通过。短序列一致性与这些控制不等于任意输入下的形式证明。

批量从 16 改为 64 的吞吐修订在查看扩展结果汇总前记录；不完整试跑保留在独立目录，未混入正式统计。下载失败后采用固定 revision、上游 LFS SHA256 校验的分段下载，没有更换样本来源。
