# Literature Layer

This directory stores evidence extracted from literature, not long prose summaries by default.

For each relevant paper, prefer recording:
- claim
- experimental setting
- population / benchmark
- controls
- result
- limitations
- relation to current hypotheses

Use papers as evidence sources, not as authorities that terminate the research loop.

Suggested lightweight record:

```yaml
paper_id: P000
title: null
source: null
claims:
  - claim_id: C000
    statement: null
    evidence_type: experimental
    supports: []
    contradicts: []
    limitations: []
```
